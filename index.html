Pertanyaan Sering Diajukan (FAQ)

Bagaimana cara memasukkan data kecamatan saya sendiri? Anda dapat mengunduh Template Excel KCDA 7 Bab menggunakan tombol di header, mengisi kolom data sesuai dengan format nama desa dan angka di kecamatan Anda, kemudian mengunggahnya melalui menu "Data Excel KCDA".
Mengapa nama desa saya tidak muncul di peta? Peta batas wilayah kecamatan digambar dinamis berdasarkan file GeoJSON. Pastikan properti "nmkec" atau "nmdesa" pada GeoJSON Anda cocok persis dengan penulisan nama kecamatan/desa di dalam file Excel.
Apakah saya bisa mengedit angka infografis langsung di layar? Ya, semua tulisan dan angka statistik di dalam kotak infografis pada menu "Editor Infografis" adalah ContentEditable. Anda dapat mengekliknya dan mengetik secara langsung, lalu perubahan akan otomatis tersimpan dalam memori.
